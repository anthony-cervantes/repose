= SLF4J HTTP Logging Filter

Logs configured request and response fields using SLF4J loggers.

== General Filter Information

* *Name:* `slf4j-http-logging`
* *Default Configuration:* `slf4j-http-logging.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/slf4j-http-logging-configuration.xsd[Schema]

== Behavior and Ordering

Log messages are produced around the downstream filter chain, so early placement observes the whole request. This filter does not modify headers or bodies. Its message-format configuration is distinct from the <<../services/http-logging.adoc#,HTTP Logging Service>> and its JTwig templates.
