= URI User Filter

Extracts a user identifier from a configured regular expression matching the request URI.

== General Filter Information

* *Name:* `uri-user`
* *Default Configuration:* `uri-user.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/uri-user-configuration.xsd[Schema]

== Behavior and Ordering

The first matching identification pattern supplies capture group 1 as `X-PP-User`. The configured group and quality are added through `X-PP-Groups` and the user header. Patterns must contain the capture group. Requests with no match continue without added identity headers. Bodies are unchanged; an uninitialized filter returns `503`.
