= Translation Filter

Applies configured XSLT transformations to requests and responses that match the configured criteria.

== General Filter Information

* *Name:* `translation`
* *Default Configuration:* `translation.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/translation-configuration.xsd[Schema]

== Behavior and Ordering

Translations can modify the HTTP message represented by the HTTPX envelope, including headers and body. Configure each translation's direction, content types, and stylesheet. Place request translations before filters that depend on the translated content; response processing runs in reverse filter order.
