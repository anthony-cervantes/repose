= Header Translation Filter

Copies configured request-header values to new header names.

== General Filter Information

* *Name:* `header-translation`
* *Default Configuration:* `header-translation.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/header-translation.xsd[Schema]

== Behavior and Ordering

Rules control whether quality values are preserved and whether the original header is removed. This filter must run before components that consume the translated headers. It does not change request bodies or response content and returns `503` until initialized.
