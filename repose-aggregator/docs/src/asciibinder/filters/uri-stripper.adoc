= URI Stripper Filter

Removes configured URI tokens from request paths and configured links in request or response content.

== General Filter Information

* *Name:* `uri-stripper`
* *Default Configuration:* `uri-stripper.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/uri-stripper.xsd[Schema]

== Behavior and Ordering

Configuration selects resources by URI pattern and HTTP method and identifies links using JSONPath or XPath. Location-header rewriting and mismatch behavior are configurable. See the schema for token indexes and the handling of links that do not match.
