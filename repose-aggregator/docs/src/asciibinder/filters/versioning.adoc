= Versioning Filter

Maps public API versions to configured origin destinations and produces version-discovery responses.

== General Filter Information

* *Name:* `versioning`
* *Default Configuration:* `versioning.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/versioning-configuration.xsd[Schema]

== Behavior and Ordering

Configure version mappings in `versioning.cfg.xml` and destinations in `system-model.cfg.xml`. Recognized resources are routed with the version's internal URI. Discovery requests can return a version document with `200`; unrecognized versions can return a choices document with `300`. An unavailable configured destination returns `502`; an uninitialized filter returns `503`.

== Metrics

This component reports the following metrics to the <<../services/metrics.adoc#, Metrics Service>>:

[cols="3", options="header,autowidth"]
|===
|Metric Type
|Metric Name
|Description

| Meter
| `org.openrepose.filters.versioning.VersioningFilter.VersionedRequest.<name>`
| Counts the number of times any request is processed using a version mapping specified by `<name>`.
`<name>` is the `id` attribute of the `version-mapping` element in this filter's configuration.
|===

[cols="1,3,3",options="header"]
|===
|Metric Type |Metric Name |Description
|Meter
|`org.openrepose.filters.versioning.VersioningFilter.VersionedRequest.<version-id>`
|Counts requests matching a configured version, including that version's discovery document.
|Meter
|`org.openrepose.filters.versioning.VersioningFilter.VersionedRequest.Unversioned`
|Counts requests without a matching version, including service discovery and choices responses.
|===
