= Exception Handling

Current Repose bundles do not register a filter named `exception`.
Do not add `<filter name="exception"/>` to the system model.

Core request handling and the servlet container handle uncaught failures.
Individual filters can also reject requests with documented status codes.
Consult the <<../architecture/filter-chain.adoc#,Filter Chain>> and each
filter's response-status documentation when selecting error handling behavior.
