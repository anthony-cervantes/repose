= Header User Filter

Builds `X-PP-User` and `X-PP-Groups` request headers from configured source headers.

== General Filter Information

* *Name:* `header-user`
* *Default Configuration:* `header-user.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/header-user-configuration.xsd[Schema]

== Behavior and Ordering

For each configured header, the first comma-separated value is trimmed and used as the user value; the source header name becomes the group. Configured quality values are attached to both generated headers. Run this before filters such as Rate Limiting that consume these headers. Bodies are unchanged; an uninitialized filter returns `503`.
