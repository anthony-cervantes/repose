= Forwarded Protocol Filter

Adds `X-Forwarded-Proto` if the request does not already contain that header.

== General Filter Information

* *Name:* `forwarded-proto`
* *Default Configuration:* `None`
* *Bundle:* `repose-filter-bundle`

== Behavior and Ordering

The value is the protocol token before `/` in `ServletRequest.getProtocol()`; for `HTTP/1.1`, the value is `HTTP`. It is not derived from the request scheme or TLS state. Existing header values are preserved. No configuration file is required, and the request and response bodies are unchanged.
