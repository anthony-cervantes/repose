= Echo Filter

Copies incoming request headers to the response and sets status `200`.

== General Filter Information

* *Name:* `echo`
* *Default Configuration:* `None`
* *Bundle:* `repose-experimental-filter-bundle`

== Behavior and Ordering

This is a terminal diagnostic filter: it does not call the rest of the filter chain or the origin service, and does not echo the request body. It has no configuration file and is shipped in the experimental bundle.
