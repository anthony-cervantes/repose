= Keystone v2 Basic Auth Filter

Exchanges configured username/secret request headers for an OpenStack Identity v2 token and supplies `X-Auth-Token` to later filters.

== General Filter Information

* *Name:* `keystone-v2-basic-auth`
* *Default Configuration:* `keystone-v2-basic-auth.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/keystone-v2-basic-auth.xsd[Schema]

== Behavior and Ordering

Successful tokens are cached in the configured datastore. Authentication failures can be delegated or rejected according to configuration. Rejected authentication uses `401` with a `WWW-Authenticate: Basic realm="RAX-KEY"` challenge; upstream authorization and availability errors can produce `403`, `500`, or `503`. See the <<keystone-v2.adoc#,Keystone v2 Filter>> for token validation and authorization.
