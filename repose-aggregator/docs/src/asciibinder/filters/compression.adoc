= Compression Filter

Decompresses gzip-encoded request bodies and compresses eligible responses using the configured compression rules.

== General Filter Information

* *Name:* `compression`
* *Default Configuration:* `compression.cfg.xml`
* *Bundle:* `repose-filter-bundle`
* link:../schemas/content-compression-configuration.xsd[Schema]

== Behavior and Ordering

Place this filter before filters that need an uncompressed request body. Compression failures caused by a non-gzip payload return `400`; other compression errors return `500`. An uninitialized filter returns `503`. Response encoding and length headers can change.
