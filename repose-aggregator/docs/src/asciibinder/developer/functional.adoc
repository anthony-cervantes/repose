= Functional Testing

Run the functional suite through the Gradle wrapper with JDK 27. Tests use
Groovy 5, Spock 2, JUnit Platform, and `spock.lang.Tag`.

[source,shell]
----
./gradlew :repose-aggregator:tests:functional-tests:integrationTest
./gradlew :repose-aggregator:tests:functional-tests:integrationTest -Prun=all --tests features.filters.apivalidator.ApiValidatorTest
----

The default selection is `smoke`. A `--tests` class filter is applied in addition
to the tag selection; use `-Prun=all` to select a specification outside the smoke tag.

== Tag Selection

[cols="1,2",options="header"]
|===
| `-Prun` value | JUnit Platform selection
| `all` | All specifications except `scaffold.category.Bug`
| `bug` | `scaffold.category.Bug`
| `core` | `scaffold.category.Core`
| `filters` | `scaffold.category.Filters`
| `identity` | `scaffold.category.Identity`
| `intense` | `scaffold.category.Intense`
| `recipe` | `scaffold.category.Recipe`
| `services` | `scaffold.category.Services`
| `xml` | `scaffold.category.XmlParsing`
| `smoke` or omitted | `scaffold.category.Smoke`
|===

For example:

[source,groovy]
----
import spock.lang.Tag

@Tag("scaffold.category.Filters")
class MyFilterTest extends ReposeValveTest {
    // Configure and exercise the filter here.
}
----

Tags can be combined; the build selects the tag requested by `run`.
`xml` selects parser-related tests but does not install a Saxon license or
run a second licensed pass automatically.

== Execution and Reports

The default is one fork. Set `-PintegrationTestMaxParallelForks=<count>` to
change the fork count, and `-PshowLog` to show standard output and error.
Test homes are created below `build/test-homes` in the functional-tests project.
HTML reports are written to `build/reports/tests/integrationTest` and XML results
to `build/test-results/integrationTest`.

For framework setup, see <<../recipes/functional-test-framework.adoc#,Functional Test Framework>>.
