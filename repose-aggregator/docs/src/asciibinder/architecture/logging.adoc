= Logging

The <<../services/logging.adoc#,Logging Service>> loads Log4j2 configuration from `log4j2.xml`.
The container configuration selects that file through `logging-configuration`.
The package example configures console output, a rolling application log, and a separate phone-home log.
Container images disable the file appenders by default and retain console output.

Use the <<../services/http-logging.adoc#,HTTP Logging Service>> for configurable access-log templates.
The <<../filters/slf4j-http-logging.adoc#,SLF4J HTTP Logging Filter>> is a separate filter with its own message format.
See <<../welcome/troubleshooting.adoc#,Troubleshooting>> for request tracing and diagnostics.
