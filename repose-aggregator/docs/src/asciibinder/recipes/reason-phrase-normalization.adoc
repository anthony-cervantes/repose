= Response Status Messages

The Jakarta Servlet 6.1 API sets the numeric response status with `setStatus(int)`.
Repose does not forward custom origin reason phrases to the HTTP status line.
For HTTP/1.1, the container supplies the status text; HTTP/2 has no reason phrase.

The former Groovy recipe that called `response.uncommit()` followed by
`response.setStatus(response.getStatus)` is no longer needed to normalize the wire response.
It should be removed from configurations that use it solely for that purpose.

== Validation Diagnostics

The <<../filters/api-validator.adoc#,API Validator>> and
<<../filters/simple-rbac.adoc#,Simple RBAC>> filters return validation diagnostics
as UTF-8 `text/plain` response bodies. Clients should inspect the numeric status
and body. These diagnostics must not be read from the reason phrase.

== Logging

The <<../services/http-logging.adoc#,HTTP Logging Service>> exposes
`outboundResponseReasonPhrase` as the standard Jetty message for the status code.
A message stored in a response wrapper for logging or error handling does not
change the container's HTTP status line.
