== What HTTP methods does *Repose* support?
Only the following HTTP methods are supported by *Repose*.

- `GET`
- `PUT`
- `POST`
- `DELETE`
- `HEAD`
- `OPTIONS`
- `PATCH`
- `TRACE`

Requests with any other HTTP method will be rejected with a response code of `400`.

== Why Use *Repose*’s Client Authentication as opposed to Keystone, Cloud Auth, or Global Auth?
SSL/TLS client authentication verifies a certificate when a connection is established.
Keystone authentication verifies an application token on each request and supplies user, tenant, and role information to later filters.
Choose certificate authentication for transport-level access control, and token authentication when the API needs user or tenant authorization.
They can be used together; see <<../recipes/client-authentication.adoc#,SSL/TLS Client Authentication>>.
