# Fake Valkyrie
This is a fake Valkyrie service for testing purposes.

The originals were taken from:

 * https://github.com/rackerlabs/repose-perf-infrastructure/blob/master/src/repose_performance/valkyrie/master/

## Runtime requirements

Use Node.js 22.12 or later and npm 10 or later, as declared in `package.json`.
Run `npm ci` in this directory to install the locked dependencies, then `node app.js` to start the service.
